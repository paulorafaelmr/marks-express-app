# Marks Express App

Sistema web para organizar viagens, fretes e o financeiro da Marks Express.

## Estado atual

- Dashboard responsivo
- Tela de viagens
- Tela de cadastro de nova viagem
- Estrutura pronta para conexão com Supabase
- Layout adaptado para computador e celular
